# 📦 패키지 공작소 — 모듈 · 패키지 · 라이브러리

> © 2026 티쳐무 · 모든 권리 보유 — 학교 수업 목적으로만 이용해 주세요. ([LICENSE](LICENSE))

고등학교 「프로그래밍」 교과서의 **모듈 · 패키지 · 라이브러리**(141·143·209쪽)를
브라우저 안의 **가상 VS Code** 에서 직접 만들고 실행해 보는 학습 앱입니다.
수행평가 「사용자 정의 패키지 제작」(5점)을 준비하도록 짰습니다.

- 파이썬 설치 없이 브라우저에서 **진짜로 실행**됩니다 — 여러 파일로 된 프로그램, `import`, 패키지 폴더까지.
  오류 문구·Traceback·밑줄(`^^^`)·`Did you mean` 이 **파이썬 3.12 와 글자까지 같습니다.**
- 오류가 나면 영어 문구 아래에 **한국어 풀이**가 붙습니다 — 「calc.py 는 mytools 폴더 안에 있어요. `from mytools import calc` 처럼 고치세요」.
- 화면은 1280×720 한 장이라 교실 TV·노트북 어디서나 스크롤이 없습니다.
- 인터넷 없이도 열립니다 (`dist/index.html` 더블클릭). 개인정보를 받지 않습니다.

### 가상 VS Code 로 할 수 있는 것
- 탐색기의 📄·📁 로 파일·폴더 만들기 — 이름 칸에 `mytools/__init__.py` 처럼 적으면 폴더까지 한 번에
- 끌어다 놓아 옮기기 · ✏️ 이름 바꾸기 · 🗑 지우기 (윈도우처럼 대소문자만 다른 이름은 못 만듭니다)
- ▶ 는 **지금 열려 있는 파일**을 실행합니다(진짜 VS Code 와 같습니다)
- 터미널에 `python main.py` · `pip install gtts` · `cls`
- Traceback 의 `File "…", line N` 을 누르면 그 파일·그 줄로 갑니다
- 「연습 과제」 에서 만든 것을 **zip 으로 내려받아** VS Code 로 그대로 열 수 있습니다

## 수행평가 조건 (2026-11-04 정함)

① 패키지 폴더 1개(영문 소문자) ② 그 안에 `__init__.py` ③ 모듈 2개 이상, 모듈마다 함수 1개 이상
④ 패키지 밖 `main.py` 에서 불러오기 ⑤ 서로 다른 import 꼴 2가지 이상 ⑥ 실행하면 모든 모듈이 오류 없이

`__init__.py` 는 파이썬 3.3 부터 없어도 import 가 되므로(이름공간 패키지), 앱은 「꼭 있어야 돌아가는 파일」이 아니라
「이 폴더는 패키지라고 밝히는 표지판」으로 가르칩니다. 조건 ②로는 그대로 두었으니 **평가 안내문에 분명히 적어 주세요.**
빠뜨려도 실행은 되므로, 루브릭상 3점(조건 부분 준수)으로 갈리기 때문입니다.

조건 점검기의 「○점 수준」 은 자기 점검 도구이며 채점 결과가 아닙니다.

## 개발

```bash
npm install
npm start            # 개발 서버
npm test             # 시험 — 진짜 파이썬 대조 122개 프로젝트 포함
npm run check:syntax # 소스 전수 검사 (문법·저작권·화면 규칙)
npm run build        # dist/index.html 한 파일 + 빌드 결과 점검
```

화면 자료(`src/data`)나 해석기를 고쳤으면 진짜 파이썬 기준을 다시 만듭니다 (파이썬 3.12 필요).

```bash
npm run golden
```
