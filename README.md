고등학교 「프로그래밍」 교과서(씨마스커뮤니케이션)의 **모듈 · 패키지 · 라이브러리**(141·143·209쪽)를
브라우저 안의 **가상 VS Code** 에서 직접 만들고 실행해 보는 학습 앱입니다.
수행평가 「모듈과 패키지」(5점 — IDLE·압축 제출 1점 + 사용자 정의 패키지 제작 4점)를 준비하도록 짰습니다.

- 파이썬 설치 없이 브라우저에서 **진짜로 실행**됩니다 — 여러 파일로 된 프로그램, `import`, 패키지 폴더까지.
  오류 문구·Traceback·밑줄(`^^^`)·`Did you mean` 이 **파이썬 3.12 와 글자까지 같습니다.**
- 오류가 나면 영어 문구 아래에 **한국어 풀이**가 붙습니다 — 「calc.py 는 mytools 폴더 안에 있어요. `from mytools import calc` 처럼 고치세요」.
- 화면은 1280×720 한 장이라 교실 TV·노트북 어디서나 스크롤이 없습니다.
- 인터넷 없이도 열립니다 (`dist/index.html` 더블클릭). 개인정보를 받지 않습니다.

### 📝 개념 정리 빈칸
화면 곳곳의 핵심 문장에서 중요한 낱말을 비워 두었습니다(화면 10곳 · 빈칸 36칸 — ① 개념 잡기 네 화면 · ② 예측 표 두 화면 · ③ 미션 네 개).
글자를 치는 동안 정답이 되면 바로 초록 ✔, 칸을 벗어날 때 틀렸으면 빨강 ✘ 이 됩니다.
카드의 **💡 힌트** 는 1단계 글자 수(○○○), 2단계 첫소리(ㅈㅅㅇ)·첫 글자를 보여 주고, 정답을 통째로 보여 주지는 않습니다.
코드 빈칸(`import`·`print` …)은 대소문자까지 맞아야 합니다. 예측 표의 정리 빈칸은 「실행해서 확인」 뒤에 열립니다(먼저 열면 채점이 예측의 답을 알려 주게 되므로).
「import 문 읽기」 와 미션은 화면이 꽉 차서 **📝 정리** 단추로 창을 열어 채웁니다(미션 1·2 는 이야기 문장 속에도 빈칸이 있습니다).
빈칸은 탭 잠금(완료 조건)에 넣지 않았고, 채운 답은 활동 기록 HTML 의 「📝 개념 정리 빈칸」 절에 함께 저장됩니다.
④ 수행평가 탭에는 문항의 답을 알려 주게 되어 넣지 않았습니다.

- 끌어다 놓아 옮기기 · ✏️ 이름 바꾸기 · 🗑 지우기 (윈도우처럼 대소문자만 다른 이름은 못 만듭니다)
- ▶ 는 **지금 열려 있는 파일**을 실행합니다(진짜 VS Code 와 같습니다)
- 터미널에 `python main.py` · `pip install gtts` · `cls`
- Traceback 의 `File "…", line N` 을 누르면 그 파일·그 줄로 갑니다
- 「연습 과제」 에서 만든 것을 **zip 으로 내려받아** IDLE·VS Code 로 그대로 열 수 있습니다

## 수행평가 문항 (5점 · 2026-11-11)

1. **IDLE 로 작성하고 압축해서 제출 (1점)** — IDLE 로 작성한 모든 파일(`foods` 폴더와 `start.py`)을 하나의 파일로 압축해서 제출한다.
   압축 파일명 예: `모듈패키지30101홍길동.zip`
2. **사용자 정의 패키지 제작 (4점)** — 다운로드 폴더에 `foods` 폴더를 만들고, 그 안에 `milk.py` · `apple.py` 를 만든다.
   - `milk.py` 의 사용자 정의 함수 `drink` 는 「신선한 우유」, `apple.py` 의 `eat` 은 「새콤한 사과」 를 출력
   - 다운로드 폴더의 `start.py` 가 `foods` 패키지를 import 하고, 두 함수를 호출해 두 줄을 차례대로 출력

채점 기준은 칸 하나에 1점입니다 — 1번 압축 제출 1점, 2번은 ① `foods` 안의 두 파일 ② `milk.py` 의 `drink( )` ③ `apple.py` 의 `eat( )` ④ `start.py` 실행 각 1점.
「연습 과제」 의 조건 점검기는 2번의 네 칸을 그대로 봅니다.
모듈 맨 아래에서 함수를 또 부른 경우, `print( )` 로 한 번 더 감싼 경우, 문구를 함수 없이 직접 print 한 경우,
`start.py` 를 `foods` 안에 둔 경우, 폴더 이름 대소문자, `milk.py.txt`, 다운로드에 남은 `foods.py` 가 패키지를 가린 경우 등을 짚어 줍니다.
1번(IDLE·압축)은 앱이 확인할 수 없어 「IDLE 에서」 화면에 따라 하기로 담았습니다.

`__init__.py` 는 문항 조건이 아니고 파이썬 3.3 부터 없어도 import 가 되므로(이름공간 패키지), 점검기는 점수 칸이 아닌
「＋ 권장」 칸으로 보여 줍니다. 채점 기준에도 없어서 **넣어도 되고 안 넣어도 됩니다.**

조건 점검기는 자기 점검 도구이며 채점 결과가 아닙니다. 모범 답은 앱 화면·자료에 넣지 않았습니다.

## 개발

```bash
npm install
npm start            # 개발 서버
npm test             # 시험 — 진짜 파이썬 대조 120개 프로젝트 포함 (수행평가 정답이 든 시험은 이 저장소에 없어 건너뜀)
npm run check:syntax # 소스 전수 검사 (문법·저작권·화면 규칙)
npm run build        # dist/index.html 한 파일 + 빌드 결과 점검
```

화면 자료(`src/data`)나 해석기를 고쳤으면 진짜 파이썬 기준을 다시 만듭니다 (파이썬 3.12 필요).

```bash
npm run golden
```
